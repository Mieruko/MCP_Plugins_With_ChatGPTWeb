Chrome giữ đăng nhập

Mỗi task có một hồ sơ Chrome/Edge lưu trên máy. Chọn đúng task, mở trình duyệt để tự đăng nhập Facebook, Colab hoặc Shopee. Sau đó bấm “Lưu và đóng” để ChatGPT dùng lại hồ sơ này.

Đổi task sẽ dùng hồ sơ khác. Hồ sơ này độc lập với Chrome cá nhân đang mở; không sao chép mật khẩu hay cookie từ hồ sơ khác. Phiên thiết lập tự đóng sau 60 phút.
