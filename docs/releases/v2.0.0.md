# V2.0.0 — Computer Use for ChatGPT Web

Released: 2026-09-29.

Version 2.0.0 adds opt-in Computer Use to the local MCP Workbench. ChatGPT Web can inspect and interact with a Workbench-managed Chrome or Edge session through scoped MCP tools.

## Highlights

- Five Computer Use tools are available in the slim MCP profile when `COMPUTER_USE_ENABLED=true`: open or close a session, observe a page, interact with visible controls, upload a file, and create or monitor a browser job.
- The Workbench adds a Computer Use dashboard for setup, session status and Stop. A user can sign in through a headed browser, then ChatGPT Web attaches to that same managed session.
- Browser profiles persist on disk. Within one Workbench server, authorized tasks and workspaces share the same browser, tabs and cookies. The profile is not a security boundary between projects, and personal Chrome/Edge profiles are not imported.
- Browser actions use observed UI references and current page state. File uploads follow task path permissions. Long-running jobs report page evidence and can be polled or monitored; they do not independently confirm an external service's state.
- An optional Windows native UI backend uses a private Python environment and foreground-window checks. Real desktop workflows remain unvalidated, and screenshots can include the full desktop.
- Native MCP images and structured results are preserved through the Workbench bridge and approval flow.

## Install or upgrade

Use Node.js 22+, npm and Git. Chrome or Edge is required only for browser Computer Use. On Windows, the separate native UI backend also requires `uv`.

For a new installation:

```powershell
git clone https://github.com/Mieruko/MCP_Plugins_With_ChatGPTWeb.git
cd MCP_Plugins_With_ChatGPTWeb
git checkout v2.0.0
npm ci
npm start
```

Computer Use is disabled by default. To enable the browser backend, install optional dependencies, build, and configure `.env`:

```powershell
npm install --include=optional
npm run build
```

```dotenv
COMPUTER_USE_ENABLED=true
COMPUTER_BROWSER=chrome
COMPUTER_BROWSER_HEADLESS=false
```

Restart the server after active tasks have ended, refresh the ChatGPT app/connector, and start a new conversation to load the Computer Use tools. Open the Workbench's **Computer Use** page to sign in to the managed browser. See the [Computer Use guide](../computer-use.md) for session permissions, shared-profile behavior, workflows and Windows setup.

For an existing installation, stop the launcher, preserve `.env`, back up the configured `WORKBENCH_PATH`, and preserve local source changes before updating:

```powershell
git fetch origin --tags
git checkout v2.0.0
npm ci
npm run build
npm start
```

## Validation record and known gaps

The [Computer Use verification record](../computer-use-verification.md) documents local browser and HTTP/MCP checks, regression results, and their limits. It does not claim successful live ChatGPT Web use through a deployed tunnel, Facebook or Colab completion, or real Windows desktop control. Windows tests cover the adapter protocol and fixtures, not real desktop interaction. Users should inspect the actual page and service state before retrying submissions or treating a job as complete.
